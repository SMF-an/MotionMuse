# MotionMuse 数据采集指南（队友版）

这份指南只说明怎样用自己的手机或电脑为 MotionMuse 拍摄训练素材。你不需要安装 Python、运行项目程序、抽取图片或标注数据。拍完后把**原始 MP4 视频**交给项目负责人，后续格式转换、抽帧和标注由项目组统一处理。

## 每位队友要采集什么

建议每位队友完成以下内容：

- 找至少 **2 块外观不同的普通长方形板子**。大小、颜色、材质或表面纹理尽量不同；不需要购买专用板，也不需要贴 ArUco 标记。
- 每块板分别录制下面四类视频，每类约 **30 秒**。
- 至少在 **2 个不同地点或光照环境**下拍摄，例如教室和宿舍、明亮环境和偏暗环境。尽量把不同动作分布到不同场景，避免所有视频都在同一个位置、同一种光线下拍完。
- 另录至少 **1 段无板负样本**，约 30 秒。画面里不出现要采集的板子；可以包含桌面、墙面或其他长方形物品作为干扰。

按最低建议量计算，每人至少交付 9 段视频：两块板各四段，再加一段无板视频。录到更多板子或场景也欢迎，请在文件名和清单中标明。

## 四类视频怎么拍

每段视频只需主要体现一种条件。动作自然、板子清楚即可，不必追求专业演奏。

| 类别 | 拍摄方法 |
| --- | --- |
| `slow` | 板子正面朝向镜头并尽量完整入镜。先静止几秒，再缓慢左右、上下移动，轻轻转动或前后倾斜。 |
| `performance` | 按平常演奏姿势拿板子，做和弦手型和扫弦动作。板子可自然小幅移动，手可以像真实演奏一样挡住部分板面。 |
| `fast` | 在板子仍大致留在画面里的情况下，较快地左右或上下移动、转动、倾斜；短暂停稳后换方向。避免整段都剧烈抖动或严重模糊。 |
| `occlusion` | 板子尽量保持不动，用手或前臂短暂挡住一个角、两个相邻角或一段边缘，然后露出几秒再换位置。不要整段盖住整块板子。 |
| `negative` | 镜头里不出现目标板子，拍一些日常背景；可让画面包含外形相似的长方形物品，帮助模型学习哪些东西不是目标板。 |

板子完全被遮住或移出画面的片段可以短暂拍摄，再把板子拿回来；这种素材用于观察系统能否重新找到板子。请不要把“板子完全不可见时也能准确定位”当作目标。

## 手机或电脑录制要求

1. 使用手机自带相机或电脑摄像头录制即可。请确认最终文件是真正的 `.mp4` 视频；不要只把 `.mov` 等文件改名成 `.mp4`。
2. 优先横屏拍摄，镜头尽量稳定。让板子和四条边尽可能完整、清晰地留在画面内，手不要长时间遮住整块板子。
3. 不要求统一分辨率或帧率，也不要求使用同一型号设备。请使用设备方便、稳定的默认设置；项目组会统一转换视频参数。
4. 不要加滤镜、字幕、贴纸或背景音乐，不要裁剪或二次压缩。请保留相机直接录制的原始视频。
5. 尽量让镜头对准板子和双手，避免录入无关人员的脸、电脑屏幕上的个人信息或其他隐私内容。分享视频前确认画面中的人员同意用于课程项目。

若设备默认保存为 `.mov` 或其他格式，请不要通过改扩展名伪装成 MP4；先使用能导出 MP4 的相机设置或工具转换，转换遇到问题时联系项目负责人。

## 文件命名与整理

每段视频单独保存。请使用下面的命名格式：

```text
P<队员编号>_B<板子编号>_<类别>_<场景编号>_<序号>.mp4
```

示例：

```text
P01_B01_slow_S1_01.mp4
P01_B01_performance_S2_01.mp4
P01_B02_occlusion_S1_01.mp4
P01_NONE_negative_S2_01.mp4
```

- 队员编号由项目负责人统一分配，例如 `P01`、`P02`、`P03`。
- 每位队友使用自己的板子编号；同一块板的所有视频保持相同编号，例如 `B01`。不同板子不能共用编号。
- 场景编号表示拍摄地点或光照环境，例如 `S1`、`S2`。
- 无板视频用 `NONE` 代替板子编号。

建议按队员和板子分文件夹整理：

```text
P01/
├── B01/
│   ├── P01_B01_slow_S1_01.mp4
│   ├── P01_B01_performance_S2_01.mp4
│   ├── P01_B01_fast_S1_01.mp4
│   └── P01_B01_occlusion_S2_01.mp4
├── B02/
│   └── ...
├── NONE/
    └── P01_NONE_negative_S2_01.mp4
```

## 怎样交付

1. 检查每段视频都能正常播放，扩展名为 `.mp4`，文件名能看出队员、板子、类别和场景。
2. 保留原始文件，不要只通过聊天软件发送可能被自动压缩的视频，可以发送压缩后的文件夹。

## 提交前快速检查

- [ ] 至少使用两块外观不同的普通长方形板子。
- [ ] 每块板都有 `slow`、`performance`、`fast`、`occlusion` 四类视频，每段约 30 秒。
- [ ] 拍摄覆盖至少两个地点或光照环境。
- [ ] 至少有一段约 30 秒的无板负样本视频。
- [ ] 视频为可播放的原始 MP4，没有滤镜、字幕或额外压缩。
- [ ] 画面里没有未经同意的无关人员或隐私信息。
