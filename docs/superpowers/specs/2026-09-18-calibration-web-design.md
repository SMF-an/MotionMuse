# MotionMuse 网页标定页设计

## 目标

为无弦吉他演奏提供演奏前标定页。用户可选择实时摄像头或本地视频，并在首帧依次点击琴头和琴颈与琴身的连接点。系统保存两个归一化坐标，供 Python 演奏程序将和弦区与扫弦区对齐吉他实际方向。

## 范围

本次实现一个本地静态网页，不引入账号、后端、云服务或视频上传服务。输入视频只在浏览器本地播放；标定结果通过下载 JSON 文件交给 Python 侧读取。

## 用户流程

1. 进入标定页，选择“打开摄像头”或“上传本地视频”。
2. 摄像头模式展示预览，用户点击“冻结画面”；视频模式自动停在第一帧。
3. 用户在画布上先点击琴头，再点击琴颈和琴身的连接处。
4. 页面用点、琴颈中线、四段和弦区和琴身扫弦带预览标定结果。
5. 用户可“重新标定”；确认后下载 `guitar_calibration.json`。
6. 演奏程序读取该 JSON，依据琴颈方向投影左手位置并依据扫弦方向投影右手运动。

## 页面与状态

- 输入选择：摄像头与文件上传互斥；选择新来源会清空旧标定。
- 画面模式：准备、等待琴头、等待琴身、已标定。
- 标定数据使用图像宽高归一化，格式为：

```json
{
  "version": 1,
  "neck_head": { "x": 0.12, "y": 0.88 },
  "neck_body": { "x": 0.52, "y": 0.54 }
}
```

- 两点距离小于画面对角线的 10% 时拒绝确认并提示用户重新点击。
- 摄像头模式在浏览器获得许可失败时显示错误，并仍允许切换到视频上传模式。

## 几何规则

- 琴颈方向：从 `neck_head` 指向 `neck_body` 的单位向量 `u`。
- 垂直方向：`v = (-u_y, u_x)`，用于定义扫弦带。
- 四个和弦段沿 `u` 均分琴颈有效长度，左手食指或手腕投影落入某段即对应 C、G、Am、F。
- 扫弦带位于琴颈末端附近，长轴沿 `v`、短轴沿 `u`。右手食指沿 `v` 穿过中线时识别上扫或下扫。

## 模块边界

- `web/calibration.html`：页面结构、样式和纯前端交互；不依赖构建工具。
- `config/guitar_calibration.json`：网页导出的运行时配置样例；真实用户配置由浏览器下载产生。
- Python 侧后续增加独立 `guitar_geometry.py` 读取 JSON 和处理投影；不把网页逻辑复制进手部追踪文件。

## 验收标准

- 摄像头和本地视频两种入口均可载入有效画面。
- 用户点击两点后能看到随吉他倾斜的琴颈、四个和弦段和扫弦带。
- 用户可重置后再次标定。
- 导出文件使用归一化坐标，且能被 Python 标准库 `json` 直接读取。
- 单个 HTML 文件可通过浏览器直接打开，无服务器依赖。

## 测试

- 使用横向与纵向视频各测试一次，确认点击坐标随画布缩放仍正确。
- 拒绝只点击一个点或两点过近的情况。
- 摄像头拒绝授权后，验证上传视频流程仍可完成。
- 使用导出的 JSON 在 Python 侧打印坐标并验证数值均为 0 到 1。
